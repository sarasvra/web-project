# clayArt 

An online store for handmade clay art products.

## Features

- Browse and view products
- User authentication and account management
- Shopping cart management
- Add products to favorites
- Product filtering and sorting
- Responsive user interface
- REST API for communication between frontend and backend

##  Technologies

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Biome

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

##  Architecture

The application uses a client-server architecture:

- **Frontend:** Handles the user interface and client-side interactions using Next.js and React.
- **Backend:** Provides API endpoints using Django REST Framework.
- **Database:** PostgreSQL stores application data.
- **API Communication:** The frontend communicates with the backend through REST APIs.

##  Project Status

This project is under development. Features and implementation details may change as development progresses.
